## Accounting and performance evidence

Tests exercise production calculation code, an independent eight-market oracle, lifecycle/history exclusions, duplicate fills, pagination, maker/taker coverage, historical fee schedules, side-correct fee-inclusive cash, missing cash, conflicting resolution sources, async races, proxy mapping, rebate scope and error states. Fixture totals remain +$61.49075 net, $4.00925 modeled fees, $1.75 wallet-wide payouts and a separate $1.25 daily maker accrual.

Fees are modeled per fill and already deducted from included settled P&L. Paid maker/taker rebates and daily maker accrual are separate views and are never added together or to the curve. The live null response is not treated as a confirmed zero. The dashboard does not reconstruct deposits, withdrawals, external transfers, open-position marks or return on capital.

Public market metadata has a bounded 12-second cache and duplicate-request sharing. A 60-request concurrency regression uses one upstream request instead of the prior 48 upstream requests plus 12 rate-limit failures. Wallet activity, positions, trades, profiles and rebates remain uncached. Newly published metadata can appear up to 12 seconds later.

The deployed HTML, CSS and JavaScript matched local bytes by SHA-256. CSS and JavaScript conditional requests returned HTTP 304; the HTML has no ETag and returned fresh HTTP 200. Health passed, POST to the data gateway returned 405, and unsupported routes/invalid wallet parameters returned 400. These checks are reproducible with `node tests/cloudflare-smoke.mjs`.
